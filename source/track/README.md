# Techspeed FuelTech Velopark

Version 0.8.0, by Alberto Wollmann Dietrich.

The Techspeed FuelTech Velopark karting circuit in Nova Santa Rita, Brazil, built for go-karts, for Assetto Corsa, BeamNG.drive and rFactor 2.

## Layouts

| Layout | Length | Direction | Max karts |
|---|---|---|---|
| Techspeed FuelTech Velopark 1000 | 1004 m | Clockwise | 24 |
| Techspeed FuelTech Velopark 1500 | 1517 m | Clockwise | 16 |
| Techspeed FuelTech Velopark 1500 Amateur | 1477 m | Clockwise | 16 |
| Techspeed FuelTech Velopark 1500 Short | 1129 m | Clockwise | 16 |
| Techspeed FuelTech Velopark 1500 Short Amateur | 1090 m | Clockwise | 16 |
| Techspeed FuelTech Velopark 1500 Short 2 | 1217 m | Clockwise | 16 |
| Techspeed FuelTech Velopark 1500 Short 2 Amateur | 1180 m | Clockwise | 16 |
| Techspeed FuelTech Velopark 1500 Hotlap | 1517 m | Clockwise | 36 |
| Techspeed FuelTech Velopark 2500 | 2541 m | Clockwise | 32 |
| Techspeed FuelTech Velopark Kids | 227 m | Anticlockwise | 3 |

Each pit box holds a team of two karts, so the number of karts is twice the number of boxes, except on the Kids layout. Techspeed FuelTech Velopark 1500 is the championship layout, with its pits at the centre building. Techspeed FuelTech Velopark 1500 Amateur is the rental layout with the easier inner corners, Techspeed FuelTech Velopark 1500 Short turns in onto the S at the first link and skips the northern loop, and Techspeed FuelTech Velopark 1500 Short Amateur is the same with the inner corners; Techspeed FuelTech Velopark 1500 Short 2 and Short 2 Amateur turn in at the second link instead. Techspeed FuelTech Velopark 1500 Hotlap has the same route as Techspeed FuelTech Velopark 1500 with its pits at the long pit building.

In hotlap mode you start just after the last sector line, so you reach the start line quickly and your first full lap is timed.

## Installing

### Assetto Corsa

Copy the `techspeed_fueltech_velopark` folder into `assettocorsa/content/tracks`. If you have an older version in a `techspeed_velopark`, `velopark` or `kart_velopark` folder, delete that folder.

Custom Shaders Patch is recommended. It adds the grass, rain effects, night lights and the live leaderboard on the start gantry. The track still loads without it, but those features are missing.

Servers need this same version of the track. The Kids layout must be added to the server as its own layout.

### BeamNG.drive

Drop `techspeed_fueltech_velopark_beamng.zip` in BeamNG's `mods` folder as it is, without unzipping it. It is the 1500's track, with every layout's start, a time trial and an AI race for each layout.

### rFactor 2

Copy the `techspeed_fueltech_velopark` folder from `techspeed_fueltech_velopark_rf2.7z` into `rFactor 2/ModDev/Locations`, then start rFactor 2 in Mod Mode (ModDev) and pick the track there. When updating, delete the old folder first.

## Known limits

- The AI lines are generated from the track geometry, not recorded from a driven lap, so AI pace may need tuning.
- rFactor 2: only in Mod Mode for now, not yet packed for rFactor 2's normal install.
